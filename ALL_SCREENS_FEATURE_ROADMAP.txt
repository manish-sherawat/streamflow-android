================================================================================
       STREAMFLOW ANDROID - COMPREHENSIVE ALL-SCREEN FEATURE ROADMAP
================================================================================

This document details feature recommendations, UI enhancements, and functionality
upgrades for every screen across the StreamFlow Android app ecosystem.

--------------------------------------------------------------------------------
1. HOME SCREEN (HomeScreen.kt)
--------------------------------------------------------------------------------
[ ] Auto-Playing Silent Trailer Loops:
    - Hero banner automatically previews a 10-second silent trailer loop when focused,
      replacing static poster backdrops.
[ ] Dynamic "Because You Watched X" Recommendation Rails:
    - Machine-learning driven rails based on user watch history and genre affinity.
[ ] Top 10 Numbered Rank Badges:
    - Overlaid 3D numbered rank badges (1 through 10) for trending titles.
[ ] Interactive Genre Chip Counts:
    - Display result counter pills next to category chips (e.g. "Anime (24)", "Movies (86)").

--------------------------------------------------------------------------------
2. TITLE DETAIL SCREEN (TitleDetailScreen.kt)
--------------------------------------------------------------------------------
[ ] In-App Official Trailer Player Dialog:
    - Tapping "Watch Trailer" opens a floating video dialog modal instead of external web view.
[ ] Dynamic Poster Palette Ambient Color Tinting:
    - Extract dominant colors from poster art via Palette API to tint screen background glow.
[ ] Season Bulk Download Manager:
    - One-tap "Download Season 1" action with batch progress notification indicator.
[ ] Episode Sort Order Toggle:
    - Ascending / Descending episode sorting toggle (Episode 1->N or Latest First).

--------------------------------------------------------------------------------
3. SEARCH SCREEN (SearchScreen.kt)
--------------------------------------------------------------------------------
[ ] Speech-to-Text Voice Search:
    - Microphone action button on search bar supporting instant voice queries.
[ ] Interactive Tag Cloud:
    - Trending search pill tags (#Cyberpunk, #TopAnime, #SciFi, #Marvel, #HotPick).
[ ] Recent Search History with One-Tap Clear:
    - Local SQLite history storing past search queries with individual delete chips.

--------------------------------------------------------------------------------
4. WATCHLIST / MY LIST SCREEN (WatchlistScreen.kt)
--------------------------------------------------------------------------------
[ ] Custom Folders & Playlist Creation:
    - Ability to categorize saved titles into custom user lists (e.g. "Weekend Binge", "Favorites").
[ ] Watch Status Badges:
    - Visual indicators for "Unwatched", "In Progress", and "Completed".
[ ] Watchlist Export & Shareable Link:
    - Generate deep links / QR codes to share watchlists with friends.

--------------------------------------------------------------------------------
5. PROFILE & ACCOUNT SCREEN (ProfileScreen.kt)
--------------------------------------------------------------------------------
[ ] Multi-User Profile Management & Kids Mode:
    - Avatar creation, PIN protection for adult profiles, and curated Kids profile mode.
[ ] Download Storage Path Selector:
    - Storage management interface allowing users to choose between Internal Storage and SD Card.
[ ] Data Saver Bandwidth Controls:
    - Toggle max streaming bitrate (e.g. 480p SD on Mobile Data, 4K on Wi-Fi).

--------------------------------------------------------------------------------
6. SETTINGS & PREFERENCES (ProfileScreen.kt & Settings Sheet)
--------------------------------------------------------------------------------
[ ] Dedicated Settings Hub Screen:
    - Structured settings sub-screens (App Preferences, Account & Security, Playback Defaults, Storage).
[ ] Custom Accent Color Theme Picker:
    - Choose primary accent color (Electric Orange, Neon Purple, Emerald Green, Cyberpunk Cyan).
[ ] Storage & Cache Cleaner Tool:
    - One-tap cache wipe button displaying current image & video buffer disk usage (e.g. "Clear 350 MB").
[ ] Wi-Fi Only Downloads & Storage Limit Sliders:
    - Enforce download rules and cap offline storage allocation (e.g. Max 10 GB).
[ ] Granular Notification Settings:
    - Toggles for New Episode alerts, Watchlist release reminders, and VIP promotion deals.

--------------------------------------------------------------------------------
7. VIDEO PLAYER SCREEN (PlayerScreen.kt)
--------------------------------------------------------------------------------
[ ] Preferred Audio & Subtitle Language Auto-Selection:
    - Automatically select user's primary language audio and subtitle track upon player load.
[ ] Skip Intro & Skip Recap Smart Buttons:
    - Timed overlay buttons to skip opening intros and previous episode recaps with 1 tap.
[ ] Touch Gesture Sensitivity Settings:
    - Custom tuning for volume and brightness drag swipe sensitivity.
================================================================================
