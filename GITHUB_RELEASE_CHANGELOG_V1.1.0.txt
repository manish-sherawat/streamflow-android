# 🎬 StreamFlow v1.1.0 — Release Notes

### 🚀 What's New
- **Category Grid View**: Tapping category chips (Movies, TV Shows, Web Series, Anime, Trending) opens a responsive 3-column grid layout with title counters.
- **Full-Screen "See All" Modal**: Displays expanded section titles in a full-screen grid window.
- **Sequential Hero Carousel**: Removed title shuffling so latest and featured titles show in exact chronological order with radial ambient glow.
- **Tuned Player Gestures**: Reduced brightness and volume drag sensitivity for smooth, precise swipe controls.
- **Electric Blue Nav Theme**: Replaced purple container colors in the floating bottom nav bar with signature Electric Blue (`#2563EB`).
- **Watchlist Auto-Sync**: Fixed "My List" auto-refresh and title resolution across all rails.
- **Pull-to-Refresh & UI Polish**: Standardized Anime World styling, fixed pull-to-refresh gestures, and removed VIP PRO badge.
